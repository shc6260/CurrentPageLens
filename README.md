# Current Page Lens

현재 보고 있는 웹페이지의 텍스트와 이미지를 **Chrome Built-in AI로 로컬 분석**하는 Chrome 확장프로그램입니다.

분석 프리셋과 사용자의 질문을 함께 적용해 중요한 내용, 확인된 사실, 관찰, 추가 확인이 필요한 항목을 구조화하고 Side Panel에 표시합니다. 일반 웹페이지, 기술 문서, 업무 이슈, 오류 화면 등 다양한 페이지에서 사용할 수 있습니다.

## 주요 기능

- **현재 페이지 수집**: 제목, URL, 본문, heading, 링크, 선택한 텍스트, 주요 UI 텍스트와 이미지 정보를 수집합니다.
- **프리셋 기반 분석**: 분석 목적에 맞는 프리셋을 선택하고 자유롭게 질문할 수 있습니다.
- **사실·관찰·불확실성 구분**: 페이지에서 직접 확인할 수 있는 사실과 AI의 해석, 판단할 수 없는 내용을 구분하도록 분석합니다.
- **원문 근거 연결**: 결과의 source 버튼으로 수집한 원문 위치를 확인할 수 있습니다.
- **이미지 분석**: 지원되는 환경에서 이미지의 글자, 관찰 내용, 불확실한 부분을 구조화합니다.
- **사용자 프리셋 관리**: 이름과 프롬프트를 저장·수정·삭제하며 로컬에 보관합니다.
- **수집·분석 상태 표시**: 모델 상태, 다운로드 진행률, 분석 과정과 오류를 표시합니다.
- **JSON 내보내기**: 분석 결과와 원문 근거를 JSON 파일로 저장할 수 있습니다.

## 분석 프리셋

| 프리셋 | 분석 내용 |
| --- | --- |
| 일반 페이지 분석 | 핵심 내용, 확인된 사실, 중요한 세부 정보, 관찰, 확인 필요 사항, 근거 |
| Jira 이슈 분석 | 요구사항, 확인된 사실, 중요 댓글·첨부 근거, 확인 필요 사항, 검색 키워드 |
| 개발 문서 분석 | 핵심 개념, API, 사용 방법, 제약사항, 예제, 주의사항, deprecated·호환성 |
| 오류/장애 분석 | 증상, 오류 메시지, 확인된 사실, 가능한 원인, 추가 확인 항목, 문서에 제시된 조치 |
| 사용자 정의 | 사용자가 작성한 프롬프트에 따른 분석 |

프리셋은 기본 분석 방향이며, 사용자의 질문을 우선 반영합니다.

예를 들어 오류/장애 분석 프리셋에서 **“이 화면에서 DB 문제로 의심할 만한 단서가 있어?”**라고 질문하거나, 개발 문서 분석에서 **“이 문서의 제약사항만 찾아줘”**라고 요청할 수 있습니다.

## 설치

별도의 빌드나 npm 설치 없이 확장프로그램을 로드할 수 있습니다.

1. 이 저장소에서 **Code → Download ZIP**으로 소스를 받거나 clone합니다.
2. 압축을 해제하고 `manifest.json`이 있는 프로젝트 폴더를 확인합니다.
3. Chrome에서 `chrome://extensions`를 엽니다.
4. **개발자 모드**를 켭니다.
5. **압축해제된 확장 프로그램을 로드합니다**를 누르고 프로젝트 폴더를 선택합니다.
6. 분석할 웹페이지에서 확장 아이콘을 클릭해 Side Panel을 엽니다.

다른 탭이나 다른 사이트로 이동했다면 해당 탭에서 확장 아이콘을 다시 클릭해 접근 권한을 부여하세요. 기본 단축키는 `Alt+Shift+A`이며 `chrome://extensions/shortcuts`에서 변경할 수 있습니다.

## 사용 방법

1. Side Panel에서 자동으로 확인한 Built-in AI 상태를 확인합니다.
2. 모델 다운로드가 필요하면 **모델 준비 / 다운로드**를 누릅니다. **현재 페이지 분석** 버튼으로도 준비를 시작할 수 있습니다.
3. 분석 프리셋을 선택하고 질문을 입력합니다.
4. 필요한 경우 이미지 분석, 현재 보이는 화면 캡처, 선택한 텍스트만 분석 옵션을 설정합니다.
5. **현재 페이지 분석**을 눌러 결과와 근거를 확인합니다.
6. 질문이나 프리셋을 바꾸고 **다시 분석**하거나, **JSON 저장**으로 결과를 내려받습니다.

### Built-in AI 초기 환경

패널을 열면 공식 `LanguageModel.availability()` API로 다음 상태를 확인합니다.

| 상태 | 안내 |
| --- | --- |
| 바로 사용 가능 | 분석을 실행할 수 있습니다. |
| 로컬 모델 다운로드 필요 | 모델 준비 또는 분석 버튼으로 다운로드를 시작합니다. |
| 모델 다운로드 중 | 다운로드와 모델 로딩이 완료되면 사용할 수 있습니다. |
| 현재 환경에서 사용 불가 | Chrome 버전, 하드웨어, 저장 공간, 브라우저 정책 등을 확인합니다. |

다운로드는 사용자 버튼 동작에서 공식 `LanguageModel.create()` API로 시작합니다. 설치하거나 패널을 여는 것만으로 다운로드나 페이지 수집을 시작하지 않습니다. 수동 `chrome://flags` 설정을 기본 사용 조건으로 요구하지 않습니다.

## 사용 환경과 수집 범위

- 데스크톱 Chrome 138 이상과 Chrome Built-in AI를 사용할 수 있는 환경이 필요합니다. 모델의 실제 사용 가능 여부는 텍스트·이미지별로 확인합니다.
- 모델 다운로드에는 네트워크가 필요하며, 다운로드 후 AI 분석은 로컬에서 수행합니다. 상세 시스템 조건은 [Chrome 공식 문서](https://developer.chrome.com/docs/ai/prompt-api)를 참고하세요.
- 한국어 UI를 제공하며 한국어 결과는 실험 옵션입니다. 모델의 언어 지원과 결과 품질은 별도로 확인해야 합니다.
- 현재 로드된 페이지 내용을 수집합니다. 접힌 댓글, 가상 스크롤 밖의 내용, iframe, CSS 배경 이미지 등은 누락될 수 있습니다.
- 이미지 분석은 모델 지원 여부와 픽셀 접근 가능 여부에 따라 달라집니다. CORS 등으로 이미지를 읽지 못하면 실패 이유와 이미지 메타데이터를 유지합니다.
- 페이지 이미지는 최대 4개를 분석하며, 현재 보이는 화면 캡처는 사용자가 선택한 경우에만 추가합니다.
- `chrome://`, Chrome Web Store, 다른 확장 페이지 등 Chrome에서 접근을 제한하는 페이지는 수집할 수 없습니다.

## 구조

페이지 수집, 분석 방향, AI 호출, 화면 표시를 분리했습니다.

| 경로 | 역할 |
| --- | --- |
| `content/` | 범용 페이지 추출과 선택적 사이트 랜드마크 식별 |
| `ai/prompts.js` | 기본 프리셋, 사실·근거 규칙, 결과 스키마 |
| `ai/analyzer.js` | 모델 상태 확인, 세션 준비, 이미지·텍스트 분석 |
| `presets/` | 사용자 프리셋의 로컬 저장과 관리 |
| `core/` | 페이지 수집과 분석을 연결하는 UI 독립 로직 |
| `sidepanel/` | 질문·프리셋 입력, 상태·결과 표시 |
| `service-worker.js` | Side Panel 실행 설정 |

Jira 처리는 제목·설명·댓글·첨부 위치를 식별하는 보조 추출기로 제한합니다. 분석 방식은 사이트별 코드가 아닌 프리셋에서 결정합니다. 핵심 분석 함수는 JSON 객체를 반환하며 UI 렌더링과 분리되어 있습니다.

## 개인정보와 권한

- 페이지 내용을 외부 AI API나 서버로 전송하지 않습니다.
- 분석 버튼을 누를 때만 페이지를 수집합니다.
- 페이지 원문과 이미지 base64를 콘솔에 기록하지 않습니다.
- 사용자 프리셋은 `chrome.storage.local`에 저장하며, 원문과 분석 결과는 패널 메모리에 유지합니다.
- 원문과 결과를 파일로 저장하는 동작은 사용자가 JSON 저장을 선택할 때 수행합니다.
- 권한은 `activeTab`, `scripting`, `storage`, `sidePanel`을 사용합니다.

## 개발 테스트

Node.js 환경에서 다음 명령으로 단위 테스트를 실행할 수 있습니다.

```bash
npm test
```

브라우저 통합 테스트는 Playwright와 Chrome for Testing이 설치된 환경에서 실행합니다.

```bash
CPA_CHROME=/absolute/path/to/chrome npm run test:browser
```
